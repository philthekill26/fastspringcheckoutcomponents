FAQ

How the demo works.

Does the landing page change the checkout code?

No. The existing components HTML, JavaScript, SDK configuration, styling and success flow are left untouched.

What happens when I click Select Advanced Monthly?

The browser navigates directly to /components, which is the same working Checkout Components demo you already had.

Are FastSpring credentials exposed on this page?

No. The landing page contains no FastSpring credentials. Your API credentials remain server-side in the existing environment variables.
