Frequently asked questions

Everything you need before checkout.

What happens when I select the plan?

You are taken to the checkout page with Advanced Monthly selected. After entering your customer details, the Python backend creates the FastSpring session and loads the checkout components.

Can I apply a coupon?

Yes. The checkout includes the FastSpring fs-coupon component so a buyer can enter and apply a coupon code before paying.

Where are payment credentials stored?

FastSpring API credentials stay server-side in environment variables. They are never exposed in the landing page or browser JavaScript.

Is this page mobile friendly?

Yes. The landing page, product card and checkout layout are responsive and designed to collapse cleanly on smaller screens.
